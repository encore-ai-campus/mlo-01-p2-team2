# `hr_result.html` 인수인계

## 책임

HR에게 대상자 정보, 업무영역별 현재값 확인 후보, 데이터 확인 필요 후보, 비교 근거와 판단 가이드를 표시한다.

## Context 계약

- `assessment`: `ContinuityAssessment`
- `guidance`: `AssessmentGuidance`

## 주요 표시

- 업무 지속 가능성·인력 검토 방향
- 대체 완료 여부·다음 확인사항
- 이름·부서·직위·근속
- 부서·직위 일치 여부
- 보류 후보의 확인 사유
- 대상 관리자·부서/직위·근속·전체 상태를 동일한 3행 카드 구조로 정렬
- 후보 이름 앞에 선택형 프로필 이미지 또는 빈 원형 자리 표시
- 일반 후보 표에는 `데이터 경고` 열을 표시하지 않음

## 검증

HR 상세, 보류 후보, 판단 가이드, 순위·승인·반려 버튼 부재 테스트

## 변경 주의

첫 행을 우선후보로 표현하지 않는다. `REVIEWABLE`을 대체 완료로, `NO_MATCH`를 채용 확정으로 표현하지 않는다. `ON_HOLD`는 내부 대체·신규채용 판단 보류와 데이터 정정 후 재조회를 명시한다. 보류 판단에 필요한 `확인 사유`는 유지하고 일반 후보 표의 불필요한 경고 열과 혼동하지 않는다.
