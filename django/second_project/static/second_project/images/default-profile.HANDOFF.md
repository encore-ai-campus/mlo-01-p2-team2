# `default-profile.png` 인수인계

## 책임

직원 사진 URL이 비어 있을 때 HR 후보 인사 카드에 표시하는 기본 프로필 이미지다.

## 표시 계약

- 원본은 448×448 PNG다.
- CSS의 96px 원형 마스크 안에서 104% 확대해 바깥 체크무늬 영역을 잘라낸다.
- 실제 직원 사진이 등록되면 `profile_image_url` 이미지가 이 자산을 대체한다.
- 후보 이름이 옆에 제공되므로 장식 이미지로 처리하고 대체 텍스트는 비워 둔다.

## 변경 주의

외부 URL이나 워터마크 이미지를 기본 자산으로 사용하지 않는다. 교체 시 정사각형 비율과 중앙 정렬을 유지한다.
