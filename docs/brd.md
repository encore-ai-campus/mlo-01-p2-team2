## 1. 배경과 문제

담당자 퇴직으로 인한 대체인력 필요 
현재 데이터 이름, 상태, 날짜로는 대체인력 구인 어려움

명료하고 직관적인 형식으로 데이터보관
추후 대체인력 후보 검토가능

## 2. 관련 담당자와 기대 결과

| 담당자 | 기대 결과 |
|---|---|
| 인사 담당자 | 퇴직 관리자와 대체 후보 수월하게 검토 |
| 업무 담당자 | 직원과 업무영역의 연결이 올바른지 확인 |
| 보안 담당자 | 이름 등 개인정보가 불필요하게 공개되지 않도록 관리 |

## 3. 목표와 확인 방법

| 목표 | 확인 방법 | 완료 기준 |
|---|---|---|
| 데이터 추후 확인 가능 | 정리된 데이터와 처음 받은 데이터를 연결 확인 | 원천데이터 95% 이상 |
| 데이터 손상 없이 보관 | 보관한 데이터와 처음 받은 데이터가 같은지 확인 | 100% |
| 정리된 데이터 오류제거 | 꼭 필요한 정보, 연결 관계, 상태, 날짜 확인 | 심각한 오류 0건 |
| 작업 과정 재확인 | 작업 기록과 처리 보류 데이터 함께 보관 | 확인에 필요한 기록 누락 0건 |

## 4. 이번에 할 일

- 처음 받은 데이터의 구성과 문제점 확인
- 처음 받은 데이터를 수정하지 않고 안전하게 보관
- 사람 이름, 부서, 직위, 업무영역, 상태, 날짜를 같은 방식으로 정리
- 직원과 업무영역, 상위 업무영역 사이의 연결이 맞는지 확인
- 다시 확인할 수 없는 데이터나 오류가 있는 데이터는 정상 데이터와 따로 보관
- 데이터 설명서, 업무 규칙, 확인 방법 작성

## 5. 이번에 하지 않을 일

- 추천 점수나 후보 순위
- 대체인력 최종 결정 및 인사발령 부여
- 인공지능 학습과 서비스 화면을 이번 작업에 포함
- 서비스 운영과 화면 구현

## 6. 업무 원칙과 제약

- 처음 받은 데이터는 수정하거나 덮어쓰지 않는다.
- 복원율은 처음 받은 전체 데이터를 기준으로 계산하며, 95% 이상을 목표로 한다.
- 관리자 상태가 `N` 또는 비활성이라고 해서 퇴직으로 단정하지 않는다.
- 등록일(`REG_DT`)이 서로 다르면 어느 데이터를 기준으로 할지 결정하기 전까지 각각 보관한다.
- 이름 등 개인정보를 작업 기록이나 발표 데이터에 그대로 공개하지 않는다.
- 향후 추천 결과가 만들어져도 최종 결정은 담당자가 직접 내린다.

## 7. 위험과 대응

| 위험 | 영향 | 대응 | 상태 |
|---|---|---|---|
| 공식 데이터 전체가 한 번에 확인되지 않을 수 있다. | 전체 데이터와 비교 어려움 | 현재 확인된 데이터를 기준으로 진행하고, 추가 데이터를 받으면 재비교 | open |
| 등록일(`REG_DT`)의 기준 데이터가 미정 | 날짜가 서로 상이 | 각 데이터의 날짜를 보관하고, 임의로 덮어쓰지 않는다. | open |
| 비활성 상태와 실제 퇴직 상태가 다를 수 있다. | 잘못된 사람을 퇴직자로 판단 | 상태의 의미가 확정되기 전에는 퇴직 여부를 결정하지 않는다. | open |
| 후보 추천 단계의 세부 기준이 아직 정해지지 않았다. | 추천 기능을 바로 완성 어려움 | 데이터 정리와 확인을 먼저 끝낸 뒤 별도 논의한다. | hold |

## 8. 완료 조건

1. 처음 받은 전체 데이터의 95% 이상을 정리된 결과에서 다시 찾을 수 있다.
2. 처음 받은 데이터가 빠짐없이 안전하게 보관되어 있다.
3. 모든 데이터가 정상 처리되었거나 처리 보류 사유가 기록되어 있다.
4. 꼭 필요한 정보의 누락, 중복, 잘못된 연결, 날짜 오류가 없다.
5. 어떤 데이터를 어떻게 정리했는지 다시 확인할 수 있다.
6. 자동 추천이나 인사 결정은 아직 확정되지 않은 내용으로 표시되어 있다.

## 9. 이 작업이 필요한 이유와 기대 효과

### 왜 필요한가

관리자 퇴직 직후 담당 업무가 비면 업무 지연
미리 데이터를 정리해 두면 관련 업무를 맡을 수 있는 사람을 빠르게 확인

### 사용 편의성

- 데이터마다 달랐던 이름과 형식이 같은 방식으로 정리되어 비교하기 쉽다.
- 결과가 처음 받은 데이터와 연결되어 있어 근거를 다시 찾기 쉽다.
- 오류가 있는 데이터는 정상 데이터와 분리되어 전체 결과를 헷갈리지 않는다.

### 업무상 이점

- 퇴직 이후 인수인계 대상을 찾는 시간을 줄일 수 있다.
- 담당자마다 다르게 판단하는 일을 줄이고, 같은 데이터를 보며 검토할 수 있다.
- 업무 공백과 중요한 업무 누락을 줄이는 데 도움이 된다.
- 반복적인 데이터 확인 작업이 줄어 인사 담당자의 부담을 낮출 수 있다.

### 기대되는 이익

- 인수인계가 빨라져 업무 중단 가능성을 낮출 수 있다.
- 후보 검토와 신규 채용에 드는 시간과 비용을 줄일 가능성이 있다.
- 판단 근거가 남아 인사 결정에 대한 설명과 확인이 쉬워진다.
- 데이터를 재사용할 수 있어 이후 비슷한 인력 공백에도 대응하기 쉽다.
